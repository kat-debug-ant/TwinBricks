# TwinBricks 2.0 – oprava pro GitHub Pages
Všechny soubory jsou přímo v kořeni ZIPu. Každá HTML stránka obsahuje vestavěné styly, skripty i logo – žádná složka assets nebo en není potřeba.
1. Rozbal ZIP.
2. V repozitáři kat-debug-ant/TwinBricks zvol Add file > Upload files.
3. Nahraj všechny soubory z rozbalené složky přímo do kořene repozitáře. Potvrď Commit changes. Staré soubory nemusíš mazat.
4. Po dokončení GitHub Pages nasazení otevři web a stiskni Ctrl+F5.
5. Každou HTML stránku je možné otevřít i lokálně bez dalších souborů. Pro navigaci potřebuješ ostatní HTML ve stejné složce.
6. Zachováno původní napojení formuláře Formspree; doručení na firemní email ověř v účtu, živou poptávku jsme netestovali.
7. Před komerčním spuštěním doplň právní náležitosti a ověř práva k fotkám a značkám.
